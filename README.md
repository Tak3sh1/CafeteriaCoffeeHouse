## 📋 Sobre o Projeto

Site institucional completo para uma cafeteria, desenvolvido para demonstrar habilidades avançadas de front-end. O projeto apresenta um design acolhedor e sofisticado, com animações suaves e experiência imersiva.

### 🎯 Demonstrações de Habilidade
- Layout responsivo com Bootstrap 5
- Animações CSS personalizadas (keyframes)
- Glassmorphism e efeitos modernos
- Scroll suave e navegação interativa
- Cards com hover effects
- Formulário de contato funcional

## ✨ Funcionalidades

- 🏠 Hero Section: com chamada principal e estatísticas
- 📖 Sobre: história e diferenciais da cafeteria
- ☕ Cardápio: 6 produtos com preços e botão de pedido
- ⭐ Depoimentos: avaliações de clientes reais
- 📞 Contato: formulário e informações de localização
- 📱 Responsividade: adaptado para todos os dispositivos

## 🚀 Tecnologias

- Bootstrap 5: Grid, componentes e utilitários
- CSS3: Animações, transitions e keyframes
- Google Fonts: Playfair Display + Inter
- Bootstrap Icons: Ícones vetoriais
